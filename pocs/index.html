PoC — CVE-2026-105080: RCE via calibre .recipe (ConvertX)

RCE CVSS 9.9 CWE-94: Code Injection ConvertX ≤ v0.18.0 · Fixed v0.19.0

Registration, upload of a malicious calibre .recipe file, conversion trigger via ebook-convert, root shell inside the container, and JWT_SECRET exfiltration from the process environment.

PoC — GHSA-h2cv-65fq-jgrp: Command Injection via -o=shell -r (yq)

Command Injection CVSS 7.8 HIGH CWE-78: OS Command Injection mikefarah/yq ≤ v4.54.1 · Fixed v4.54.2

Demonstration of the command injection in yq's shell output format (-o=shell). When -r (raw output) is combined with -o=shell, unquoted strings containing shell metacharacters are emitted literally — piping to sh or using eval on the output executes arbitrary commands. The video shows the vulnerable yq -o=shell -r '.key' pattern, the injected payload via YAML value, and successful command execution on the host.

Affected: mikefarah/yq ≤ v4.54.1. Fixed in v4.54.2 (2026-10-23). The fix quotes all shell output format values. Tested on Linux x86_64.

PoC — GHSA-9c7h-xjrp-8gh3: XSS in SnapOtter (2 demos)

XSS CVSS 7.1 HIGH CWE-79: Cross-site Scripting SnapOtter ≤ v2.2.0 · Fixed v2.3.0

Two proof-of-concept demonstrations for the reflected XSS vulnerability in SnapOtter's /api/v1/shorten endpoint. The url parameter is reflected unsanitized in the JSON response, enabling script execution when the API response is consumed by a vulnerable frontend.

Full exploit walkthrough (1:41)

End-to-end exploitation: craft malicious URL payload, trigger via API, demonstrate JavaScript execution in victim context, exfiltrate session token, achieve account takeover.

Minimal XSS payload execution (7 s)

Short clip showing the bare XSS payload javascript:alert(1) executing in the response context — confirms the reflection point without the full exploit chain.

Affected: SnapOtter ≤ v2.2.0. Fixed in v2.3.0 (2026-11-03). The fix applies proper output encoding on the url parameter in the shorten endpoint response.
